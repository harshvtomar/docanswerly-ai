# DocAnswerly AI

*Upload Documents. Ask Questions. Get Answers.*

*An AI-powered multilingual document intelligence platform for extracting knowledge and answering questions from English and Hindi PDF documents.*

Session 1 development in progress. This describes the project vision; AI inference is not yet enabled.

## Development
Node.js 24. Run `npm ci`, `npm test`, `npm run build`, or `npm run dev`.

React + TypeScript + Vite frontend. GitHub Pages hosts static files only. PDF.js and Tesseract.js will process PDFs locally. Never put private API keys in frontend code.

See PROJECT_STATE.md for verified progress. Live deployment is not yet verified.
